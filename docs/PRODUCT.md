# Product

Map is intended to become an AI-native geographic platform for local services. Instead of only
displaying nearby businesses, it should eventually help a person move from a need to discovery,
comparison, availability, and a completed action.

Milestone 1 is deliberately narrower: an installable PWA mapping foundation for Vilnius, Lithuania.
The active application uses React, TypeScript, and MapLibre GL JS, while Windows is the primary
development and local-infrastructure platform. There is currently no AI, booking, authentication,
payment, routing, or provider workflow.

The immediate product value is architectural learning: locally controlled geographic data, a stable
API boundary, a native map client, and a development workflow that does not require macOS for most
backend and data work. Geographic and functional expansion must follow measured milestones.
